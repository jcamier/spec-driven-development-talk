## Coding Standards

The agent must follow:

- Existing project patterns first
- Simple code over clever code
- Clear names over abbreviated names
- Small functions over large functions
- Explicit error handling
- No unrelated refactors
- No speculative abstractions
- No new dependency without justification

## Quality Bar

All implementation must include:

- tests for new behavior
- validation of edge cases
- clear error handling
- no unrelated file changes
- no generated code that is unused
- no excessive test duplication
- documentation updates when behavior changes

## Agent Role

The agent is responsible for:

- generating code
- generating tests
- generating validation logic
- explaining tradeoffs
- identifying ambiguity
- preserving existing patterns

The agent must not:

- invent new requirements
- silently change architecture
- expand scope without approval
- optimize before correctness
- add unnecessary abstractions

## Human Feedback Loop

Human review is required when:

- requirements are ambiguous
- architecture changes
- security or privacy is affected
- new dependencies are introduced
- generated code changes public behavior
- tests pass but the design seems questionable
